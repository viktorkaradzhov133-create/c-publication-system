# C++ Publication System

An educational C++ project demonstrating object-oriented programming principles through a publication class hierarchy.

## Concepts Demonstrated

- Object-Oriented Programming (OOP)
- Multilevel Inheritance
- Polymorphism
- Virtual Functions
- Function Overriding
- Constructors
- Pointers

## Class Structure

- Publication – stores the title.
- Book – extends Publication with an author.
- Textbook – extends Book with a subject.

## How to Run

Compile using a C++ compiler:

`g++ -std=c++11 main.cpp -o publication`
